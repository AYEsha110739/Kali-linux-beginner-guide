# Kali Linux Beginner Guide

This project explains basic penetration testing using Kali Linux.

## Tools Used
- Nmap
- Wireshark
- Aircrack-ng

## Example Command
nmap -sV 192.168.1.1

This scans a target device and shows open ports and services.

## Purpose
This project helps beginners understand cybersecurity tools and network security testing.
